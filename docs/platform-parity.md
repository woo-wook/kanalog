네이티브는 독립 로컬 프로필이므로 기존 웹 인증/서버 DB를 강제로 공유하지 않는다. 현재 단계에서 웹 진도와 네이티브 진도의 자동 동기화를 구현했다고 표현하지 않는다.


## 변경 절차

1. 공통 기능/콘텐츠 계약이나 발음 변환을 바꾸면 shared fixture를 먼저 갱신한다.
2. 웹 API/화면, Android 코어/Compose, Swift 코어/SwiftUI를 함께 반영한다. 플랫폼 고유 API는 해당 플랫폼 구조에 맞게 구현한다.
3. 각 플랫폼 테스트·빌드 및 모바일 화면 검증 결과를 `docs/verification.md`에 남긴다. 설치/실기기 제약을 통과로 표시하지 않는다.

## 현재 차이

- 네이티브 홈은 가나 전체 분류와 N5~N1 단어·문법 범위 선택을 제공한다. 웹의 서버 레슨별 경로·계정·DB는 별개이며 네이티브에 서버 연결을 요구하지 않는다.
- 네이티브 7/30일 답변·고유 카드·연속일은 로컬에 저장된 모든 평가(가나·단어·문법·즉시 보강)를 포함한다. 같은 ID는 기간별 한 번만 고유 카드로 센다. 웹의 기존 지표는 서버 ReviewLog 집계를 유지한다. 서로 다른 저장소의 숫자가 자동으로 같아지는 것은 아니다.
- 날짜는 선택 시간대의 자정을 기준으로 오늘 포함 7/30일을 계산하고, 오늘 기록이 없으면 어제부터 연속일을 센다. 기기 시각보다 미래인 기록은 네이티브 집계에서 제외한다.
- 네이티브 원본·미리 생성된 음성은 로컬 파일이다. 원본이 없는 항목의 TTS는 기기의 일본어 음성 지원이 필요하다. 웹 Supertonic 서버와 네이티브 계산 엔진을 혼동하지 않는다.
- 콘텐츠 catalog와 진도 동기화는 후속 범위다. installer/버전·해시 계약은 지금 준비하며 학습 시작 시 다운로드를 요구하지 않는다.
