# 플랫폼 동시 변경 매트릭스

모든 사용자 기능 변경은 Web / Android / iOS와 공통 계약을 함께 확인한다. 실행 불가한 플랫폼은 사유와 정확한 다음 검증 명령을 남긴다.

| 기능 | Web | Android | iOS | 공통 검증 |
| --- | --- | --- | --- | --- |
| 가나 전체/분류 혼합·참고표 | 기존 구현 | 이번 작업 | 이번 작업 | 기본46/탁음20/반탁음5/요음33, 두 문자208 |
| 문법 정답 숨김·원본 강조 | 기존 구현 | 이번 작업 | 이번 작업 | 공개 전 뜻/설명 없음 |
| 후리가나·한글 보조 | 기존 구현 | 이번 작업 | 이번 작업 | 동일 ReadingGuide/설정 |
| 레벨 전체 단어/문법·FSRS | 기존 서버 | 기기 로컬 | 기기 로컬 | 평가별 due/상태 보존 |
| 검색·북마크·제외·개인 단어 | 기존 구현 | 이번 작업 | 이번 작업 | 콘텐츠와 개인 상태 분리 |
| 통계·설정·재시작 | 기존 DB | 기기 로컬 | 기기 로컬 | timezone와 원자적 영속성 |
| 콘텐츠 업데이트 | MAX import | 공통 패키지 | 공통 패키지 | 동일 id 진도 유지 |
| 음성 | 원본/Supertonic | 로컬 파일/기기 TTS | 로컬 파일/기기 TTS | 네트워크 음성 필수 의존 없음 |

네이티브는 독립 로컬 프로필이므로 기존 웹 인증/서버 DB를 강제로 공유하지 않는다. 현재 단계에서 웹 진도와 네이티브 진도의 자동 동기화를 구현했다고 표현하지 않는다.
