# 로드맵

## P0

개인 계정, JLPT MAX v2.1.2의 N5 어휘·문법 import, 원본 음성, FSRS 복습, 사용자별 진도, 반응형 웹과 PWA 기본 형태, 자체 서버 Compose를 우선한다. 학습 시작 기본값은 N5 어휘와 하루 새 카드 10장이다. 실제 지원 카드·미디어 수는 [데이터 출처](data-sources.md)에 기록한다. 이 문서는 현재 완료 여부를 대신하지 않으며 환경별 검증 범위는 [운영 문서](operations.md)에 기록한다.

## 이후

1. 더 많은 APKG 스키마와 카드 방향을 지원하되 원본 템플릿의 임의 JavaScript 실행은 허용하지 않는다.
2. 별도 권리를 확보한 상용 콘텐츠를 개인 MAX 데이터와 분리하고 결제·공개 계정을 설계한다.
3. 오프라인 학습의 충돌 처리, 모바일 앱 패키징, 말하기·SJPT 연습을 독립 단계로 검토한다.

MAX 개인 덱이 상용 앱의 기본 제공 콘텐츠가 되는 것으로 간주하지 않는다. 이로이로 자산과 안키 엔진 코드는 포함하지 않는다.
