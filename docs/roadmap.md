# 로드맵

## P0

개인 계정, JLPT MAX v2.1.2의 N5 어휘·문법 import, 원본 음성, FSRS 복습, 사용자별 진도, 반응형 웹과 PWA 기본 형태, 자체 서버 Compose를 우선한다. 사용자 지시에 따라 학습 시작을 가타카나 → 히라가나 → N5 어휘·문법 코스로 전환했으며 하루 새 카드 기본 한도는 10장이다. Supertonic 3 브라우저 합성을 기본 음성 엔진으로 추가하고 원본 MAX·기기 음성도 선택 가능하게 했다. 실제 지원 카드·미디어 수는 [데이터 출처](data-sources.md)에 기록한다. 현재 완료 여부와 미실행 항목은 [검증 기록](verification.md)을 따른다.

## 이후

1. 더 많은 APKG 스키마와 카드 방향을 지원하되 원본 템플릿의 임의 JavaScript 실행은 허용하지 않는다.
2. 별도 권리를 확보한 상용 콘텐츠를 개인 MAX 데이터와 분리하고 결제·공개 계정을 설계한다.
3. 오프라인 학습의 충돌 처리, 모바일 앱 패키징, 말하기·SJPT 연습을 독립 단계로 검토한다.

MAX 개인 덱이 상용 앱의 기본 제공 콘텐츠가 되는 것으로 간주하지 않는다. 이로이로 자산과 안키 엔진 코드는 포함하지 않는다.

### 레벨 전체 학습 확장

홈의 계정별 N5~N1 레벨 설정, 단어/문법 전체 연습, 급수 전체/모든 레벨 예정 복습, 세션 내 오답 재연습 및 다음날 보강을 추가했다. 기존 단계별 코스와 가나 전체 연습을 함께 유지한다. 자동 레벨 진단·객관식 자동 채점은 이번 기능에 포함하지 않는다. 이후에는 충분한 실제 학습 기록을 바탕으로 레벨 추천을 검토한다.
