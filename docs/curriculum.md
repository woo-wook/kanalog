# 왕초보부터 고급까지 학습 커리큘럼

## 구성 원칙

학습 화면은 **레벨 → 단원 → 레슨 → 복습**으로 이어진다. 홈에는 현재 단계와 이어서 할 레슨 하나를 보여준다. 전체 코스에서는 여섯 레벨을 선택할 수 있고, 레벨 화면에서는 현재 단원을 펼쳐 레슨 순서를 보여준다. 다른 단원은 목차로 접어 두고 필요할 때 펼친다. 이미 마친 레슨도 복습할 수 있다.

레벨 이름은 앱 내부의 학습 단계다. MAX에 표시된 JLPT 급수를 그대로 연결하며 시험 합격이나 회화 능력을 보장하는 등급으로 표시하지 않는다. 현재 자료로 가능한 문자 읽기, 단어 읽기·뜻·예문 확인, 문법 회상을 중심으로 한다.

## 현재 전체 개인 데이터 기준 목차

| 레벨 | 학습 목표 | 현재 콘텐츠 | 기본 단원 | 기본 레슨 |
| --- | --- | --- | ---: | ---: |
| 1 · 왕초보 | 히라가나와 가타카나를 보고 읽기 떠올리기 | 기본 문자 46자씩, 합계 92자 | 4 | 20 |
| 2 · 입문 · N5 | 기초 단어의 읽기·뜻 연결, 기본 문법 문장 회상 | 어휘 779장 + 문법 99장 | 10 | 59 |
| 3 · 초급 · N4 | 어휘 범위를 넓히고 문법 형태·의미 구별하기 | 어휘 878장 + 문법 62장 | 11 | 57 |
| 4 · 중급 · N3 | 예문과 함께 표현의 의미·문장 구조 익히기 | 어휘 1,719장 + 문법 217장 | 22 | 130 |
| 5 · 중고급 · N2 | 어휘·문법 설명을 연결하고 반복 회상하기 | 어휘 2,632장 + 문법 271장 | 33 | 187 |
| 6 · 고급 · N1 | 고급 표현의 읽기·의미·쓰임을 구별하고 복습하기 | 어휘 3,151장 + 문법 429장 | 43 | 244 |

기본 경로 합계는 123단원·697레슨·10,329장이다. MAX 10,237장에 기본 문자 92장을 더한 값이다. 왕초보의 선택 확장 2단원·12레슨·116장은 이 기본 진도에서 제외한다. 실제 화면의 수치는 로그인한 계정이 가져온 콘텐츠와 학습 제외 상태로 계산한다. 아직 가져오지 않은 급수는 데이터 없음으로 표시한다.

## 왕초보: 문자와 소리 연결

1. **히라가나 시작**: 모음 → 카 행 → 사 행 → 타 행 → 나 행. 5개 레슨·25자.
2. **히라가나 기본 완성**: 하 행 → 마 행 → 야 행 → 라 행 → 와 행·응. 5개 레슨·21자.
3. **가타카나 시작**: 같은 행 순서로 기본 25자. 5개 레슨.
4. **가타카나 기본 완성**: 나머지 기본 21자. 5개 레슨.

한 레슨에서 문자 모양 확인 → 음성 듣기 → 읽기 떠올리기 → 정답 확인 → 자기 평가를 반복한다. 로마자와 한글은 읽기 보조이며 정확한 발음의 대체물로 설명하지 않는다. 탁음·반탁음·요음은 각 문자 체계의 선택 확장 단원에 두며 입문 레벨 진입을 막지 않는다.

## 순서를 섞어 문자 익히기

왕초보 화면의 **가나 섞어 연습**에서 히라가나(기본값)·가타카나·둘 다를 고르고 기본·탁음·반탁음·요음을 조합한다. 5·10·20·30장씩 또는 선택 범위 전체를 연습할 수 있다. 예를 들어 기본+탁음+반탁음을 두 문자 체계로 섞으면 142장, 요음까지 포함하면 208장이 범위가 된다. 기존 행별 레슨도 유지한다.

학습·복습은 기존 카드 ID와 FSRS 상태로 기록하고 원래 행별 레슨의 진도에도 반영한다. 자유 연습은 아직 복습일이 아닌 문자까지 다시 볼 수 있지만 답변을 따로 저장하며 복습일·코스 진도·통계에는 반영하지 않는다. 이 구분은 시작 화면과 완료 화면에 표시한다. 한 세션은 정해진 장수로 끝나고 **다시 섞어 연습**으로 새로운 세션을 만든다. 기존 선택 레슨과 진도는 보존하며 새 계정의 기본 경로는 히라가나부터 시작한다.

## 입문~고급: 단어와 문장을 함께 연습

각 단원은 현재 레슨을 사용해 최대 어휘 4개·문법 2개 레슨을 배치한다. 기본 흐름은 다음과 같다.

**단어 읽기·뜻 연결 → 단어 확장 → 문법 문장 회상 → 단어·예문 연습 → 단어 확장 → 문법 문장 회상**

어휘 레슨은 기존 인식 카드 최대 20장, 문법 레슨은 기존 회상 카드 최대 5장이다. 단어는 일본어 표기 → 가나·한국어 뜻 → 원본 예문·해석·음성 순서로 확인한다. 문법은 실제 일본어 질문 → 원본 일본어·한국어 설명을 확인하고 자기 평가한다. 모든 레슨에 없는 별도 대화나 말하기 채점 활동을 추가했다고 표시하지 않는다.

레벨마다 어휘와 문법의 양이 다르므로 둘을 전체 단원에 비례 분산한다. 예를 들어 N4는 11단원마다 문법 1~2개 레슨을 배치한다. N1은 43단원마다 어휘 3~4개와 문법 2개 레슨을 배치한다. 마지막 단원에 한 종류의 레슨만 몰리지 않도록 한다. 계정에 한 종류만 가져왔다면 확보된 레슨만 제공한다.

단원 이름은 현재 데이터에 맞는 **단계 이름 + 단어와 문장 + 번호**다. 실제 자료에는 급수·품사·예문이 있지만 인사·식당·여행 등 주제별 태그와 선수 학습 관계가 없다. 문법의 Kind는 비표시 placeholder이며 UnitID는 노트 고유 식별자다. 원본 노트 ID 순서를 검증된 주제·난이도 순서라고 설명하지 않는다. 주제별 커리큘럼은 추후 실제 항목을 검토해 별도 매핑할 수 있다.

## 진도와 다음 레슨

- **첫 연습 카드 수**: 보통 또는 쉬움 평가가 한 번 이상 있는 활성 카드 수.
- **레슨 첫 연습 완료**: 제외하지 않은 모든 활성 카드에 위 평가 기록이 있는 상태.
- **단원 완료**: 활성 레슨의 첫 연습이 모두 끝난 상태.
- **레벨 완료**: 선택 확장을 제외한 모든 활성 기본 레슨의 첫 연습이 끝난 상태.
- **학습한 카드 수**: 평가 종류에 관계없이 한 번 이상 답변한 카드 수. 첫 연습 완료 수와 구분한다.

추천은 선택한 미완료/복습 레슨을 우선한다. 이후 레벨·단원 순서의 미완료 기본 레슨 → 선택 확장 → 복습 레슨을 안내한다. 원하는 레벨로 직접 이동할 수 있다. 완료는 첫 연습의 진도이며 장기 암기 완료를 의미하지 않는다. FSRS 복습은 이후에도 계속된다.

하루 새 카드 한도는 모든 레벨이 공유한다. 기본 한도 10장을 권장하며 카드 20장 레슨은 여러 날에 나눠 연습할 수 있다. 세션이 끝났어도 레슨에 첫 연습이 남아 있으면 다음 단원을 완료한 것으로 표시하지 않는다.

## 데이터와 구현

`GET /api/curriculum`은 인증된 사용자의 기존 코스·레슨을 레벨과 단원으로 묶는 읽기 API다. `GET /api/curriculum/levels/{key}`는 한 레벨을 반환한다. 버전 `1`의 고정 키는 `starter`, `n5`, `n4`, `n3`, `n2`, `n1`이다.

카드·레슨 ID, 원본 콘텐츠, FSRS 상태, ReviewLog는 그대로 유지한다. 기존 `/api/courses`와 레슨 학습 API도 유지한다. 커리큘럼 조회는 카드를 예약하거나 학습 상태를 갱신하지 않는다. 새로운 DB migration이나 복습 기록 초기화는 없다.
