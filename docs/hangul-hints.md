# 한글 발음 보조 표기

한글 보조 표기는 가나 읽기의 근사치다. 원본 읽기와 일본어 음성이 기준이며, 보조 표기는 기본적으로 숨긴다. JLPT MAX v2.1.2에는 한글 발음 필드가 없으므로 import 때 자동 생성하지 않는다. 사용자가 직접 입력하거나 검토한 값만 `hangulHint`에 저장한다. 검토되지 않은 변환 결과를 학습 화면에 표시하지 않는다.

개인 보조 표기를 작성할 때에는 아래 규칙을 일관되게 적용한다.

| 일본어 표기 | 보조 표기 원칙 | 예 |
| --- | --- | --- |
| 장음 (`おう`, `おお`, `えい`, `ー`) | 늘어난 모음을 한 번 더 적어 길이를 보인다. 실제 말소리는 원본 음성으로 확인한다. | `こう` → `코오`, `せんせい` → `센세에` |
| 촉음 (`っ`, `ッ`) | 다음 자음의 막힘을 앞 음절 받침으로 나타낸다. 자음에 따라 ㄱ·ㅅ·ㅂ을 쓴다. | `がっこう` → `각코오`, `きって` → `킷테`, `いっぱい` → `입파이` |
| 요음 (`ゃ`, `ゅ`, `ょ`) | 앞 가나와 합친 한 음절로 적는다. | `しゃ` → `샤`, `きょう` → `쿄오` |
| `ん` | 뒤따르는 자음에 따라 들리는 코소리를 반영한다. ㅂ·ㅍ·ㅁ 앞은 ㅁ, ㄱ·ㅋ 앞은 ㅇ을 우선한다. 불확실하면 보조 표기를 비워 둔다. | `さんぽ` → `삼포`, `げんき` → `겡키` |

이 표기는 일본어의 모음 길이, 자음 조음, 억양을 정확히 옮기지 못한다. 특히 사람 이름·외래어·연음은 예외가 많으므로 자동 치환만으로 확정하지 않는다. 원본 음성이 없는 항목은 기기에서 일본어 음성이 제공될 때에만 선택적 TTS를 사용할 수 있다.
