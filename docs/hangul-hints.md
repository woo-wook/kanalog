# 한글 발음 보조 정책

`reading`은 원본/등록한 일본어 읽기이며 `hangulHint`는 사용자가 직접 입력한 별도 보조 값이다. MAX에는 전용 한글 발음 필드가 없다. 수동 값이 있으면 우선하며 없으면 확인 가능한 가나 읽기로만 자동 근사값을 계산한다. 원본 데이터나 수동 값을 자동 값으로 덮어쓰지 않는다.

## 설정과 표시

기본 꺼짐이며 **한글 발음 보조 표시**로 제어한다. 카드·문법 예문·단어 예문·단어장에 동일하게 적용한다. 가나도 설정을 무시하고 보조를 강제하지 않는다. 단어 카드는 정답 전 읽기 힌트 설정과 함께 적용한다. 자동 생성은 **근사 발음 · 자동**으로 구분한다. 정확한 발음·원어민 녹음·검수 완료로 표기하지 않는다.

## 변환 규칙

- 가타카나는 비교/변환 시 히라가나로 정규화한다. 출력 일본어 표기는 바꾸지 않는다.
- 요음은 두 글자를 한 모라로 처리한다: きゃ → 캬, しゅ → 슈, ちょ → 초. ティ/ファ 등 주요 외래어 작은 모음도 조합으로 처리한다.
- 장음 ー는 앞 모음에 따라 아/이/우/에/오를 추가해 길이를 표시한다. コーヒー → 코오히이. 통상적인 おう/えい 연속도 오오/에에로 근사한다. 발음이 분리되는 어휘는 예외일 수 있으므로 음성과 함께 확인한다.
- 촉음 っ은 뒤 자음에 따라 앞 음절에 ㄱ/ㅂ/ㅅ 받침을 붙인다: がっこう → 각코오, きっぷ → 킵푸, きって → 킷테.
- ん은 앞 음절과 뒤 자음에 따라 ㄴ/ㅁ/ㅇ 받침으로 근사한다: しんぶん → 심분, かんこく → 캉코쿠. 음절 경계와 실제 비음은 한국어와 다르다.
- 문장 전체의 형태소 분석에서 조사로 확인한 は/へ/を는 와/에/오로 처리한다. 단어 자체의 は/へ는 무조건 조사로 바꾸지 않는다. 원본 ruby의 읽기는 우선한다.
- 구두점과 공백은 보존한다. 읽기 미상의 한자·라틴 문자·숫자가 남으면 확인 가능한 부분을 변환하고 미확인 원문을 `〔 〕`에 남긴다. **일부 읽기 확인 필요**와 별도 설명으로 완전한 발음과 구분한다. 확인 가능한 가나가 전혀 없으면 발음 대신 표시 불가 안내를 제공한다.
- 후리가나 조각 사이에도 촉음·비음의 문맥을 이어서 처리한다. 조사나 단어 경계의 `え + い`를 장음으로 잘못 합치지 않도록 모음 경계를 별도로 보존한다.
- 원본 ruby 읽기는 그대로 두고, 원본에 읽기가 없는 한자 구간만 해당 구간에 완전히 포함된 사전 토큰으로 보완한다. 원본 ruby 일부를 잘라서 추측하지 않는다.
- 작은 모음·작은 야/유/요·역사적 가나는 명시적으로 지원하며 장음과 요음 조합을 우선 처리한다. 숫자의 조수사나 약어를 임의로 발음으로 바꾸지 않는다.

API `hangulStatus`는 `COMPLETE / PARTIAL / UNAVAILABLE`이다. 수동 보조가 있으면 수동 값을 우선한다. `COMPLETE`는 입력 읽기의 변환이 모두 가능했다는 의미이며 사람이 발음을 검수했다는 뜻은 아니다.

한국어로 일본어 음운·악센트·모라를 완전히 나타낼 수 없다. 이 표기는 초기 읽기 보조이며 정확한 가나와 음성이 학습 기준이다. 원본 후리가나/사전 읽기의 우선순위와 지원 범위는 [furigana.md](furigana.md)에 기록한다.
