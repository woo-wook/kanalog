## 문법 제목과 원본 강조 (2026-10-02)

지원하는 기본 문법 1,078개 전체의 `FrontHTML`에서 `<mark class="_j4y">`를 확인했다. 강조된 일본어를 제목으로 사용하고 예문의 정확한 위치를 텍스트 조각으로 보존한다. `Kind`의 보이지 않는 구분 문자는 제목으로 쓰지 않는다. 별도 정식 문형명 필드는 확인되지 않아 활용 공식이나 새 설명을 생성하지 않는다. 기존 한국어 핵심 표현·뉘앙스·접속·비교 설명은 원문 그대로 구분해 보여준다. 전체 1,078개·N5 99개의 앞면 복원과 강조 일치를 검증했고 미복원은 0개다. 실전 문제 유형의 다른 표시 규칙은 지원 범위에 추가하지 않았다.

## 이용 범위

[공식 NOTICE](https://github.com/truthyblue/jlpt-max-deck/blob/main/NOTICE)는 공식 릴리스 자산의 개인 학습용 다운로드와 사용을 허용한다. 이 고지는 프로젝트 소프트웨어의 AGPL-3.0-or-later와 덱 데이터·생성 음성의 권리를 구분하며, 덱 데이터와 음성의 미러링·판매·재포장·수정·재배포 권한을 부여하지 않는다. JMdict 유래 필드에는 별도 EDRDG/CC BY-SA 4.0 조건이 있을 수 있다. 생성 음성의 도구와 모델은 NOTICE에 AivisSpeech 1.2.0, まい 모델 및 ACML 1.0으로 적혀 있다. 이 저장소에는 APKG 본문, 추출 JSONL, 음성, 원본 템플릿 코드를 넣지 않는다. 상용 콘텐츠 제공에는 별도 권리 확인 또는 교체 데이터가 필요하다.

### 후리가나 복원 (2026-10-04~05)

기존 개인 MAX 2.1.2 APKG와 checksum을 다시 검증하고 읽기 메타데이터만 갱신했다. 지원하는 전체 문법 1,078개, 단어 예문 10,976개에 원본 ruby를 복원했으며 예문 22개는 원본 ruby가 없다. 단어의 전체 읽기는 기존 원본 Reading 필드를 유지한다. 세부 매핑/자동 사전 보조/한글 근사 표기 한계와 갱신 명령은 [furigana.md](furigana.md)에 기록한다. 원문과 음성 파일은 여전히 private-data 및 사용자 소유 volume에만 둔다.
