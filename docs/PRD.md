# 일본어 학습 P0 제품 요구사항

## 목표
개인 서버에 설치해 JLPT MAX의 N5 어휘와 지원되는 문법을 학습한다. 동일 계정의 진도는 PostgreSQL에 저장한다. MAX 원본과 미디어는 계정별 비공개 데이터로 보관한다.

## 사용자 흐름
관리자 CLI로 계정 생성 → MAX APKG를 비공개 경로에 다운로드·변환·가져오기 → 로그인 → 덱 선택 → 어휘/문법 카드의 답 확인 → 네 단계 자기 평가 → FSRS 복습 → 다른 브라우저에서 이어 학습.

## P0 범위
계정과 소유권, 안전한 쿠키 인증, 덱별 신규 한도와 복습 큐, 학습 기록의 멱등성과 동시성, 원본 음성, 개인 단어장, 검색, 설정, 통계, 모바일 화면, PWA, Compose 배포.

## 제외
임의 Anki 템플릿 실행, 공개 가입, 회화 AI, 결제, 오프라인 답변 동기화, 상용 콘텐츠 번들.

## 완료 판단
실제 APKG의 지원 항목과 미디어를 가져오고 import report를 확인한다. 한 카드 평가 후 DB 재조회로 진도가 유지된다. 중복 답변과 다른 사용자의 콘텐츠 접근이 차단된다. 로컬 Compose 실행·백업·복원 절차를 문서화한다.
