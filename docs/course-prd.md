# 코스로 시작하는 일본어 학습

현재 화면 구조는 후속 지시의 **왕초보~고급 레벨 → 단원 → 레슨**이다. 기존 데이터를 사용한 실제 목차와 완료 정의는 [현재 커리큘럼](curriculum.md)을 따른다. 아래 초기 코스 전환 설계의 카드·레슨은 그대로 보존하고 그 위에 레벨별 진도 읽기 모델을 제공한다.

2026-10-01 사용자 지시에 따라 학습 시작점을 가타카나 → 히라가나 → 기초 일본어로 바꾼다. 가져온 JLPT MAX 데이터는 어휘·문법의 콘텐츠 공급원이며 화면의 학습 단위는 코스와 작은 레슨이다.

## 학습 흐름

1. 가타카나: ア・イ・ウ・エ・オ부터 오십음도 행 단위로 기본 46자를 연습한다. 탁음·반탁음·요음은 추가 레슨으로 구분한다.
2. 히라가나: あ・い・う・え・お부터 같은 순서로 기본 46자를 연습한다.
3. 기초 어휘 N5: MAX에서 가져온 779장을 약 20장씩 레슨으로 나눈다. 학습 화면에서는 레슨 안에서 일일 신규 카드 한도만큼 소개한다.
4. 기초 문법 N5: 확보한 99장을 약 5개씩 나눈다. 어휘와 함께 선택해서 연습할 수 있다.
5. N4~N1: 같은 콘텐츠 구조로 이어진다. 사용자가 직접 선택할 수 있고 처음 홈에서는 가타카나 첫 레슨을 추천한다.

가나 문자·로마자 대응은 자체 작성한 기본 문자표이며 MAX APKG의 콘텐츠로 표시하지 않는다. [문부과학성 가나 표](https://tsunagarujp.mext.go.jp/assets/download/hiragana_katakana_ver202210.pdf)를 대응 확인 자료로 쓴다. 자료의 디자인·그림·음성은 복제하지 않는다. 한글 읽기는 근사 표기로 명시한다. 쓰기·필순·받아쓰기 자동 채점은 이번 범위에 포함하지 않는다.

## 화면

- 홈: 오늘 복습, 새 카드 한도, 학습 기록, 현재 또는 추천 레슨, 이어서 학습.
- 코스: 권장 순서로 코스를 표시하고 각 레슨의 문자/학습량과 첫 연습 진행 상황을 제공한다. 원본 덱 이름을 학습 진입 기준으로 쓰지 않는다.
- 레슨: 문자나 질문 → 읽기/뜻 확인 → 자기 평가. 가나는 뜻 퀴즈 대신 소리를 떠올리도록 안내한다. 레슨 카드 순서는 오십음도 또는 원본 노트 ID를 기준으로 안정적으로 유지한다. 어휘의 이 순서는 주제별 난이도 검증을 마친 순서라고 주장하지 않는다.
- 완료: 이번 학습의 고유 카드/답변 수와 다음 복습 시각을 표시하고 코스로 돌아간다. 다음 레슨은 코스 안의 아직 첫 연습을 완료하지 않은 레슨을 추천한다.

## 저장과 진도

기존 노트, 카드, 사용자 FSRS 상태, ReviewLog는 유지한다. 코스/레슨은 이 카드 위에 매핑한다. 가나에는 별도의 사용자 소유 카드를 만든다. 사용자별 활성 레슨을 저장하고 다른 기기에서 이어간다. 초기화·재import는 코스 매핑을 멱등하게 갱신하며 기존 진도를 삭제하지 않는다.

학습함은 한 번 이상 평가한 카드 수다. 첫 연습 완료는 레슨의 모든 카드에 보통 또는 쉬움 평가가 최소 한 번 존재하는 상태다. 이는 영구 암기나 객관적인 기억 확률을 뜻하지 않는다. 추가 가나 레슨은 필수 기본 46자의 코스 추천 진행을 막지 않는다. 코스 전체를 잠그지는 않으며 사용자가 필요한 레슨으로 이동할 수 있다. 일일 새 카드 한도·UTC 저장·시간대·중복 요청·다른 기기 충돌 검사는 기존 서버 정책을 유지한다.

## 음성

MAX 어휘는 인증된 원본 MP3를 듣기 버튼으로 재생한다. 재생 상태와 실패 이유를 보여주고 수동 오디오 컨트롤을 제공한다. 자동재생은 설정을 켠 경우에만 시도하며 브라우저가 막으면 수동 버튼을 안내한다. [브라우저 play API의 실패/자동재생 정책](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/play)을 따른다.

가나에 원본 음성이 없으면 사용자가 일본어 기기 음성을 명시적으로 선택해 들을 수 있다. 일본어 음성이 없는 기기는 기능 불가를 표시한다. 문법 APKG 노트에는 현재 원본 음성 참조가 없어 이를 정직하게 표시한다. 서버 파일 수·HTTP 성공만으로 음성 동작 검증을 마쳤다고 판단하지 않고 실제 브라우저 디코딩과 재생 시간 진행, 음원의 비무음 여부를 확인한다. 스피커 출력과 휴대폰 청취 품질은 별도 실기기 검증이다.

후속 사용자 지시에 따라 기본 엔진을 Supertonic 3 브라우저 합성으로 변경했다. 일본어 읽기 또는 가나 글자, 문법의 일본어 예문을 합성한다. 원본 MAX 및 기기 음성은 비교·대체 선택으로 유지한다. 엔진과 10개 목소리 선택은 계정에 저장한다. 모델은 개인 서버의 별도 디렉터리에 두며 첫 사용 때 약 401MB를 불러온다. 생성된 WAV는 메모리에서만 재생하며 새 요청·카드 전환·페이지 이탈 시 이전 재생을 정리한다. 실제 합성 재생의 최종 검증 상태는 `verification.md`를 따른다.

## 테스트 계정

전용 QA 계정으로 로그인, MAX 어휘 청취, 가타카나 첫 레슨, 평가 저장, 재로그인 진도 유지, 코스 소유권, 모바일 넘침을 검증한다. 비밀번호는 무작위 생성해 Git에서 제외된 권한 0600 파일에 둔다. 실제 개인 계정의 복습 상태를 테스트로 변경하지 않는다.
