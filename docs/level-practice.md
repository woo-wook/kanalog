# 레벨 전체 연습과 오답 복습

## 사용자 흐름

- 홈에서 내 학습 레벨 N5~N1을 선택한다. 설정은 계정에 저장되어 다른 기기에서도 이어진다. 가나는 기존 왕초보 문자 연습에서 별도로 다룬다.
- **단어 연습 / 문법 연습**: 선택한 급수의 가져온 카드 전체가 범위다. 현재 레슨·선택한 덱에 묶이지 않는다. 배운 카드 중 복습 시각이 된 항목을 먼저, 하루에 남은 새 카드 한도만큼 미학습 항목을 무작위로 선택한다.
- **N5 전체 복습** 같은 급수 전체 복습: 해당 급수의 단어와 문법 중 배운 카드만 선택한다. 새 카드는 들어가지 않는다.
- **모든 레벨 복습**: 급수와 현재 커리큘럼에 관계없이 소유한 준비 완료 단어·문법 덱에서 복습 대상을 선택한다. 급수가 없는 개인 단어도 이미 배웠다면 이 범위에 들어간다.
- 복습은 한 세션에 최대 50장이다. 남은 복습은 새로운 세션으로 계속할 수 있다. 새 카드 한도는 모든 학습 진입에서 함께 적용되고 서버가 답변 트랜잭션에서 집행한다.
- 제외한 카드·비활성 카드·다른 계정 데이터·준비되지 않은 import는 범위에 들어가지 않는다.
- 코스 레슨 화면은 유지하며, 급수 화면에서도 단어 전체 / 문법 전체 / 급수 전체 복습을 시작할 수 있다.

## 다시 평가

1. 주 학습에서 `다시`를 누르면 공식 java-fsrs 1.0.0이 계산한 상태와 due를 원자적으로 저장한다.
2. 같은 트랜잭션에서 그 세션의 즉시 재연습 1회와 다음날 복습 알림을 예약한다.
3. 남은 원래 카드 뒤에 재연습 카드가 나온다. 재연습은 별도 `reinforcement_answer`로 저장하며 FSRS 상태와 새 카드 사용량을 변경하지 않는다. 어떤 평가를 눌러도 이번 즉시 재연습은 종료한다. 끝없는 반복으로 세션을 늘리지 않는다.
4. 재연습에서 성공해도 다음날 복습은 남는다. 다음날 이전에 별도의 예정 FSRS 복습에서 성공해도 다음날 알림은 유지한다.
5. 다음날 알림 시각이 되면 같은 카드가 모든 레벨 / 급수 / 유형 / 기존 레슨의 예정 학습 범위에서 다시 후보가 된다. 실제 제출은 서버가 현재 상태·version과 알림 도달을 확인하고 공식 FSRS로 새 상태를 계산한다. 성공하면 도달한 알림을 삭제하고, 다시 평가하면 다음날로 새로 예약한다.

주 학습은 카드당 세션 1회, 즉시 재연습도 카드당 세션 1회다. FSRS due를 덮어쓰지 않고 다음날 알림을 별도 `review_followup` 테이블에 저장한다. 브라우저가 보낸 복습 시각을 신뢰하지 않는다. 자동 객관식 채점이 없으므로 오답은 사용자의 `다시` 자기 평가를 뜻한다.

## 시간·정합성·집계

- 다음날은 평가 순간의 사용자 시간대에서 다음 날짜 00:00이다. 저장은 UTC이다. 이후 시간대 설정을 바꾸더라도 이미 예약한 UTC 시각은 유지하며, 새 평가는 새 시간대로 예약한다. Seoul 자정 전후와 미국 DST 경계를 테스트한다.
- 사용자 → 카드 잠금 순서를 유지한다. 서로 다른 기기의 같은 state version / retry version 제출은 하나만 성공한다. 새 카드 하루 한도도 사용자 행 잠금으로 여러 범위에 걸쳐 집행한다.
- 주 평가·자유 연습·즉시 재연습 전체에서 idempotency key 충돌을 검사한다. 주 평가의 재연습 응답 스냅샷도 저장하여 재연습 완료 뒤 원래 요청을 재전송해도 같은 성공 응답을 반환한다.
- GET은 학습 진도를 변경하지 않는다. 세션 생성과 답변만 명시적인 POST이다.
- URL의 sessionId로 새로고침 때 남은 카드, 재연습 여부, 고유 카드 ID와 평가 분포를 서버에서 복원한다. 소유하지 않은 세션은 404이다.
- 세션 완료의 고유 카드 수 / 답변 수 / 평가 분포에는 즉시 재연습을 포함한다. 홈·장기 학습 통계는 기존 ReviewLog 기준을 유지하여 즉시 반복을 추가 암기 카드나 FSRS 복습 횟수로 집계하지 않는다.
- 홈의 예정 복습 수는 선택한 레슨이 아닌 전체 소유 카드의 FSRS 예정 또는 도달한 다음날 알림의 합집합이다. 같은 카드가 두 조건을 만족해도 1장이다. 급수별 단어·문법 수는 연습 가능한 카드의 실제 DB 집계다.

## 운영

V9는 설정/세션/카드 예약/ReviewLog에 컬럼을 추가하고 재연습 및 다음날 알림 테이블을 만든다. V10은 빈 세션을 새로고침할 때 한도·대기·다음 복습 안내를 보존하기 위한 queue_info_json 컬럼만 추가한다. 기존 카드 ID·원본 콘텐츠·미디어·FSRS JSON·version·복습 기록을 재작성하거나 초기화하지 않는다. 배포 전 PostgreSQL dump와 기존 컬럼의 테이블별 해시를 개인 백업 디렉터리에 기록하고 배포 직후 비교한다.
